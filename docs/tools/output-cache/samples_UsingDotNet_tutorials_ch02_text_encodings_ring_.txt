1. the bytes of the text 'Cafe' with an accent, a space and the euro sign:
   UTF-8   9 bytes   43 61 66 C3 A9 20 E2 82 AC
   UTF-16  12 bytes  43 00 61 00 66 00 E9 00 20 00 AC 20
   Latin-1 6 bytes   43 61 66 E9 20 3F
   ASCII   6 bytes   43 61 66 3F 20 3F
   UTF-8 uses 1 byte for the letters of English and 2 to 4 for the others; UTF-16 uses 2 or 4; Latin-1 has one byte for 256
   characters and no euro sign (it becomes ?); ASCII has 128 characters.

2. the byte order marks:
   File.WriteAllText with no encoding writes UTF-8 and no BOM: first bytes 43 61 66
   with UTF8Encoding(True) the file starts with EF BB BF   (the BOM of UTF-8)
   with the UTF-16 encoding the file starts with FF FE and has 14 bytes   (the BOM FF FE: little endian)

3. File.ReadAllText finds the BOM:
   the UTF-8 file:  yes
   the UTF-16 file: yes
   the UTF-16 file, with UTF-8 given as the encoding: yes   (a BOM in the file wins over the given encoding)

4. a Latin-1 file without BOM:
   read as UTF-8:   6 bytes, the last character is the replacement sign (EF BF BD): yes
   read as Latin-1: yes  (the same text as 'Cafe' with the accent)

5. is it valid UTF-8?
   the UTF-8 file:   yes
   the Latin-1 file: no
   a plain English file is valid UTF-8 and valid Latin-1: yes
