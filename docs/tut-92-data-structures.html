Tutorial 92: More data structures

Lists and dictionaries are not always the best tool. This lesson shows five collections of .NET that keep order for you or save memory — a priority queue, a sorted set, a sorted dictionary, a linked list and a bit array — and when each one is the right choice.

What you will learn#

  • PriorityQueue: always the most urgent item first,
  • SortedSet: no duplicates and always sorted,
  • SortedDictionary: keys in order,
  • LinkedList: cheap changes at both ends and next to a node,
  • BitArray: a million yes/no values in 125 KB, with logic operations,
  • the Ring words that need callMethod (Get, And, Or).

Tutorial 4 used List and Dictionary, and tutorial 89 the collections for many threads.

The program#

docs/tutorials/t92_data_structures.ring
# Tutorial 92: more data structures - PriorityQueue, SortedSet, SortedDictionary, LinkedList and BitArray
load "dotnet.ring"
using {
	"System"
	"System.Collections"
	"System.Collections.Generic"
}

func main
	cInt = "System.Int32"
	cText = "System.String"

	# 1. PriorityQueue<element, priority>: Dequeue always gives the element with the SMALLEST priority, whatever the order of Enqueue.
	oTasks = dnNewGeneric("System.Collections.Generic.PriorityQueue",[cText,cInt],[])
	oTasks.callMethod("Enqueue",["write the report",3])
	oTasks.callMethod("Enqueue",["fix the server",1])
	oTasks.callMethod("Enqueue",["answer the mail",5])
	oTasks.callMethod("Enqueue",["call the customer",2])
	? "1. " + oTasks.getProp("Count") + " tasks, most urgent first:"
	while oTasks.getProp("Count") > 0
		? "   " + oTasks.callMethod("Dequeue",[])
	end

	# 2. SortedSet: no duplicates, always sorted. Add answers false for a value that is already there. Min and Max are ready.
	oSet = dnNewGeneric("System.Collections.Generic.SortedSet",[cInt],[])
	for n in [42,7,19,7,3,42,100]
		oSet.callMethod("Add",[n])
	next
	? nl + "2. sorted set of 7 numbers with duplicates: " + oSet.getProp("Count") + " kept, from " + oSet.getProp("Min") + " to " + oSet.getProp("Max")
	? "   in order: " + list2str2(oSet.toList())
	? "   Contains(19): " + oSet.callMethod("Contains",[19]) + ", Contains(20): " + oSet.callMethod("Contains",[20])

	# 3. SortedDictionary: keys stay in order, so a loop over it is alphabetical
	oDict = dnNewGeneric("System.Collections.Generic.SortedDictionary",[cText,cInt],[])
	for cName in ["pear","apple","fig","banana"]
		oDict.callMethod("Add",[cName,len(cName)])
	next
	cKeys = ""
	for cKey in oDict.getProp("Keys").toList()
		cKeys += cKey + " "
	next
	? nl + "3. sorted dictionary, keys in order: " + cKeys

	# 4. LinkedList: items are linked to their neighbours. Adding or removing at either end, or next to a known node, is quick.
	oList = dnNewGeneric("System.Collections.Generic.LinkedList",[cText],[])
	oList.callMethod("AddLast",["b"])
	oList.callMethod("AddLast",["c"])
	oList.callMethod("AddFirst",["a"])
	oNodeB = oList.getProp("First").getProp("Next")
	oList.callMethod("AddAfter",[oNodeB,"b2"])
	? nl + "4. linked list: " + list2str2(oList.toList()) + " (first = " + oList.getProp("First").getProp("Value") + ", last = " + oList.getProp("Last").getProp("Value") + ")"
	oList.callMethod("Remove",["b"])
	? "   after Remove(b): " + list2str2(oList.toList())

	# 5. BitArray: one bit for each item, so a million yes/no values take 125 KB. Set, Get and the logic methods And, Or, Xor, Not.
	#    (Get, And and Or are words that Ring does not accept after a dot, so they are called with callMethod. And and Or change the array they are called on.)
	oBits = dnNew("BitArray",[ :length = 10 ])
	oBits.Set(1,True)
	oBits.Set(3,True)
	oBits.Set(4,True)
	oOther = dnNew("BitArray",[ :length = 10 ])
	oOther.Set(3,True)
	oOther.Set(9,True)
	? nl + "5. bits:  " + bitText(oBits)
	? "   other: " + bitText(oOther)
	? "   AND:   " + bitText(dnCopyBits(oBits).callMethod("And",[oOther]))
	? "   OR:    " + bitText(dnCopyBits(oBits).callMethod("Or",[oOther]))

func dnCopyBits oBits
	return dnNew("BitArray",[ :bits = oBits ])

func bitText oBits
	cText = ""
	for i = 0 to oBits.Length - 1
		if oBits.callMethod("Get",[i]) cText += "1" else cText += "0" ok
	next
	return cText

func list2str2 aList
	cText = ""
	for item in aList
		cText += "" + item + " "
	next
	return cText

How it works#

Closed generic types#

All of them but BitArray are generic: dnNewGeneric(type, [type arguments], [constructor values]) makes a closed type such as PriorityQueue<string, int>. They have no Ring class, so the objects are used in the plain style: callMethod("Add", [value]), getProp("Count"), and toList() to copy a collection into a Ring list (Core concepts).

PriorityQueue#

Enqueue(element, priority) adds; Dequeue() returns the element with the smallest priority number, whatever the order of adding. It is the right tool for a to-do list by urgency, for events by time, and for algorithms such as the shortest path. It does not keep the whole list sorted (it only knows the next item), so it is faster than sorting again and again.

SortedSet#

A set holds each value once: adding 42 twice keeps one 42. A SortedSet also keeps the values in order, so Min, Max and a loop come for free, and Contains is fast even for a million items.

SortedDictionary#

Same as a Dictionary, with the keys in order. The loop over Keys gives apple banana fig pear. Use it when the order matters for display; use the plain Dictionary when only the speed of the lookup matters.

LinkedList#

Each item is a node that knows its neighbours (Next, Previous). AddFirst, AddLast and AddAfter(node, value) do not move other items, and Remove of a known node is quick. The price: no access by number. Take it when you add or remove in the middle of a long list all the time, for example an undo list or a play list.

BitArray#

One bit for each item. A million yes/no values (a sieve of primes, which seats are free, which files were seen) take 125 KB instead of megabytes. Set(index, value) and Get(index) write and read one bit (Get is called with callMethod, see below); And, Or, Xor and Not work on all the bits at once and change the array they are called on, so the program copies it first (new BitArray(bits)). In the output, AND has only the bit that both arrays have and OR has the bits of either.

Note

Ring accepts most of its own words as method names after a dot (Set, From, To, Step, In, On, Off), but not Get, And and Or (a statement get x reads input, and and, or are the operators of conditions). A .NET method with one of those names is called with callMethod("Get", [...]).

What you learned#

  • five collections and what each one is for,
  • the plain style (callMethod, getProp, toList) for closed generic types,
  • BitArray operations change their own array,
  • the few Ring words that must be called with callMethod.

Exercises#

  1. Make a task list with PriorityQueue where two tasks have the same priority: in which order do they come out? (Do not rely on it.)
  2. Use a SortedSet of words to print the words of a text without duplicates in alphabetical order.
  3. Find all primes below 1000 with a BitArray (the sieve of Eratosthenes).
  4. Build an undo list of the last 5 actions with a LinkedList.
