Tutorial 42: A folder browser

A tree of folders on the left, the files of the chosen folder on the right, and the totals at the bottom. A small Explorer, with TreeView and ListView.

What you will learn#

  • TreeView and its nodes, and the Tag property,
  • ListView in details mode with columns,
  • building a tree from folders recursively,
  • reacting to the user's choice,
  • formatting file sizes.

The controls#

ControlShowsYou use
TreeViewa hierarchyNodes, Node.Nodes, SelectedNode, event AfterSelect
ListViewa list with columnsView = "Details", Columns, Items, ListViewItem.SubItems

The program#

docs/tutorials/g42_browser.ring
# Tutorial 42: a folder browser - a TreeView of folders, a ListView of files, and the details of a file
load "dotnet.ring"
dnUseDesktop()
using {
	"System"
	"System.IO"
	"System.Drawing"
	"System.Windows.Forms"
}

oForm = ""
oTree = ""
oList = ""
oStatus = ""
cRoot = ""

func main
	# The folder to browse: this program makes a small demo folder (give another folder as the first argument to browse it)
	cRoot = makeDemoFolder()
	if len(sysargv) >= 3 and sysargv[3] != "--selftest"
		cRoot = sysargv[3]
	ok

	oForm = uiForm("Folder browser",640,360)

	# The pieces: a SplitContainer with the folders on the left and the files on the right, a status line at the bottom
	oSplit = new SplitContainer() {
		Dock = "Fill"
	}
	oForm.Controls.Add(oSplit)
	oSplit.SplitterDistance = 200

	oTree = new TreeView() {
		Dock = "Fill"
	}
	oSplit.Panel1.Controls.Add(oTree)

	oList = new ListView() {
		Dock = "Fill"
		View = "Details"                    # columns, like Explorer
		FullRowSelect = True
		GridLines = True
	}
	oList.Columns.Add_2("Name",180)
	oList.Columns.Add_2("Size",80)
	oList.Columns.Add_2("Modified",130)
	oSplit.Panel2.Controls.Add(oList)

	oStatus = uiLabel(oForm,"",0,0,640,22)
	oStatus.Dock = "Bottom"

	# fill the tree from the folder, and react when the user picks a node
	oRootNode = addFolderNode(oTree.Nodes,cRoot)
	oRootNode.Expand()
	oTree.setAfterSelectEvent("folderChosen()")
	oTree.SelectedNode = oRootNode

	uiTest(oForm,"selfTest()")
	uiRun(oForm)
	uiEnd()

# A node for a folder, with a node for each subfolder below it. The Tag of a node remembers the full path.
func addFolderNode oNodes, cFolder
	oNode = oNodes.Add(new Path().GetFileName(cFolder))
	oNode.Tag = cFolder
	for cSub in sort(new Directory().GetDirectories(cFolder).toList())
		addFolderNode(oNode.Nodes,cSub)
	next
	return oNode

# The user picked a folder: list its files
func folderChosen
	cFolder = oTree.SelectedNode.Tag
	oList.Items.Clear()
	nFiles = 0
	nBytes = 0
	for cFile in sort(new Directory().GetFiles(cFolder).toList())
		oInfo = new FileInfo(cFile)
		oItem = new ListViewItem().New_1(oInfo.Name)
		oItem.SubItems.Add(sizeText(oInfo.Length))
		oItem.SubItems.Add(oInfo.LastWriteTime.ToString_1("yyyy-MM-dd HH:mm"))
		oList.Items.Add(oItem)
		nFiles++
		nBytes += oInfo.Length
	next
	oStatus.Text = "  " + cFolder + "   -   " + nFiles + " files, " + sizeText(nBytes)

# a size in bytes as text: 1536 -> 1.5 KB
func sizeText nBytes
	if nBytes < 1024
		return "" + nBytes + " B"
	ok
	if nBytes < 1024 * 1024
		return uiNumber(floor(nBytes / 102.4) / 10) + " KB"      # uiNumber: 1.5, not Ring's fixed 1.50
	ok
	return uiNumber(floor(nBytes / 104857.6) / 10) + " MB"

# a demo folder with folders and files
func makeDemoFolder
	cBase = new Path().Combine(new Path().GetTempPath(),"tutorial42")
	if new Directory().Exists(cBase)
		new Directory().Delete([ :path = cBase, :recursive = True ])
	ok
	for cName in ["Projects/Ring","Projects/Web","Pictures","Documents/2024"]
		new Directory().CreateDirectory(new Path().Combine(cBase,cName))
	next
	new File().WriteAllText(new Path().Combine(cBase,"readme.txt"),"A demo folder")
	new File().WriteAllText(new Path().Combine(cBase,"Projects/Ring/main.ring"),copies("? 'hello'" + nl,40))
	new File().WriteAllText(new Path().Combine(cBase,"Projects/Ring/notes.txt"),copies("some notes ",100))
	new File().WriteAllText(new Path().Combine(cBase,"Projects/Web/index.html"),"<html></html>")
	new File().WriteAllText(new Path().Combine(cBase,"Documents/2024/report.txt"),copies("report line" + nl,500))
	return cBase

func copies cText, nTimes
	cResult = ""
	for nIndex = 1 to nTimes
		cResult += cText
	next
	return cResult

func selfTest
	dnAssert("the root node",oTree.Nodes.Count,1)
	dnAssert("the root has three subfolders",oTree.Nodes.Item(0).Nodes.Count,3)
	dnAssert("the root folder has one file",oList.Items.Count,1)
	# pick the folder Projects > Ring
	oProjects = oTree.Nodes.Item(0).Nodes.Item(2)          # sorted: Documents, Pictures, Projects
	dnAssert("the node is Projects",oProjects.Text,"Projects")
	oTree.SelectedNode = oProjects.Nodes.Item(0)
	dnAssert("two files in Ring",oList.Items.Count,2)
	dnAssert("the first file",oList.Items.Item(0).Text,"main.ring")
	dnAssert("the status shows the folder and the totals",substr(oStatus.Text,"2 files") > 0,True)
	dnAssert("a size text",sizeText(1536),"1.5 KB")
	dnAssert("a small size",sizeText(300),"300 B")
	new Directory().Delete([ :path = cRoot, :recursive = True ])
Output
SELFTEST OK (9 checks)

How it works#

A demo folder#

makeDemoFolder creates folders and files in the temp folder, so the tutorial can show a result and be tested anywhere. Give the program a real folder as its first argument to browse it: ring g42_browser.ring "C:\Users\you\Documents".

Building the tree#

addFolderNode(nodes, folder) makes one node for the folder and then calls itself for every subfolder: that is recursion, the natural way to walk a tree. Folders are sorted so the order is stable. The important line:

Ring
oNode.Tag = cFolder

Tag is a free property that can hold anything: here the full path of the folder. The node's Text is only the name; when the user picks a node, the program reads its Tag to know which folder it is.

Tip

For a very big tree, build only the first level and add the subfolders when a node is expanded (event BeforeExpand). Walking a whole disk at start would take too long.

Reacting to the choice#

setAfterSelectEvent("folderChosen()") runs when a node is selected. The function reads oTree.SelectedNode.Tag, clears the list, and adds a ListViewItem for every file: new ListViewItem().New_1(name) makes the row with its first column, and SubItems.Add(text) fills the other columns (size, modified date).

The ListView#

View = "Details" shows columns like Explorer; Columns.Add_2("Name",180) adds a column with a title and a width in pixels; FullRowSelect highlights a whole row; GridLines draws lines. A ListView can also show icons (LargeIcon, SmallIcon, List).

File sizes#

sizeText turns 1536 into 1.5 KB. uiNumber(...) formats a number without Ring's fixed two decimals (otherwise 1.5 would be written 1.50).

Testing#

The test checks the tree (one root, three subfolders), selects a node by code (oTree.SelectedNode = ..., which raises the same event as a click), and checks the list and the status line. It also tests sizeText as a plain function.

What you learned#

  • recursion builds a tree,
  • Tag carries data on a node,
  • ListView details mode,
  • selection events fill the other control.

Exercises#

  1. Show an icon for folders and files (an ImageList).
  2. Sort the list when the user clicks a column header (ColumnClick).
  3. Open a file with a double-click (Process.Start with UseShellExecute = True).
  4. Add a Refresh button that reloads the tree.

The full-size version is the FileExplorer application.
