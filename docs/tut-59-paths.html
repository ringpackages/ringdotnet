Tutorial 59: Paths and the environment

Programs that work on every computer build paths with Path.Combine, ask the system for special folders and read settings from environment variables. This lesson shows each one.

What you will learn#

  • building and taking apart paths with the Path class,
  • relative and absolute paths,
  • cleaning a text so that it is a valid file name,
  • special folders (documents, temporary files),
  • environment variables with a default value,
  • how .NET null arrives in Ring.

Why not add strings?#

"reports" + "\" + "2024" works on your computer only: other systems use /, and an extra separator or a missing one breaks the path. Path.Combine chooses the separator of the system and never doubles it.

The program#

docs/tutorials/t60_paths.ring
# Tutorial 60: paths and the environment - building paths safely, splitting them, special folders and environment variables
load "dotnet.ring"
using {
	"System"
	"System.IO"
}

func main
	oPath = new Path()

	# 1. Build a path with Combine, never with + "\": Combine uses the right separator for the system and never doubles it
	cFile = oPath.Combine_3("reports","2024","january.txt")
	? "1. Combine: " + cFile
	? "   Combine with a rooted second part restarts the path: " + oPath.Combine("reports","/etc/hosts")

	# 2. Take a path apart
	cFull = "C:\data\reports\2024\summary.final.txt"
	? nl + "2. file name      : " + oPath.GetFileName(cFull)
	? "   without suffix : " + oPath.GetFileNameWithoutExtension(cFull)
	? "   extension      : " + oPath.GetExtension(cFull)
	? "   folder         : " + oPath.GetDirectoryName(cFull)
	? "   change the extension: " + oPath.ChangeExtension(cFull,".csv")

	# 3. A path can be relative (to the current folder) or absolute (complete): GetFullPath makes it absolute
	cAbsolute = oPath.GetFullPath("data.txt")
	? nl + "3. is 'data.txt' rooted? " + yesNo(oPath.IsPathRooted("data.txt")) + "; its full path is rooted? " + yesNo(oPath.IsPathRooted(cAbsolute))
	? "   it ends with the same name: " + yesNo(oPath.GetFileName(cAbsolute) = "data.txt")

	# 4. Characters a file name may not contain
	cBad = "report: 1/2?.txt"
	cGood = cBad
	for cChar in ["\","/",":","*","?",'"',"<",">","|"]       # the characters Windows does not allow in a name
		cGood = substr(cGood,cChar,"_")
	next
	? nl + "4. '" + cBad + "' becomes '" + cGood + "'"

	# 5. Special folders: do not write the user's name into your code, ask the system
	oEnvironment = new Environment()
	cDocuments = oEnvironment.GetFolderPath("MyDocuments")
	? nl + "5. the documents folder exists? " + yesNo(new Directory().Exists(cDocuments))
	? "   the temporary folder exists? " + yesNo(new Directory().Exists(oPath.GetTempPath()))

	# 6. Environment variables: settings from outside (a password, a folder, a mode). Always provide a default.
	oEnvironment.SetEnvironmentVariable("TUTORIAL60_MODE","fast")
	? nl + "6. TUTORIAL60_MODE = " + oEnvironment.GetEnvironmentVariable("TUTORIAL60_MODE")
	cMissing = oEnvironment.GetEnvironmentVariable("TUTORIAL60_NOT_SET")
	if isobject(cMissing)                                 # .NET null comes to Ring as an object that IsNull()
		cMissing = "(default)"
	ok
	? "   a variable that is not set: " + cMissing
	oEnvironment.SetEnvironmentVariable("TUTORIAL60_MODE",NULL)

	# 7. The system: which one runs the program
	? nl + "7. 64-bit process? " + yesNo(oEnvironment.Is64BitProcess) + ", the new line is " + len(oEnvironment.NewLine) + " character(s) long"

func yesNo lValue
	if lValue
		return "yes"
	ok
	return "no"
Output

2. file name      : summary.final.txt

   it ends with the same name: yes

How it works#

Combine and split#

Path.Combine joins parts (two parts: Combine, three: Combine_3, four: Combine_4). Careful: if a later part is rooted (starts with a separator or a drive), the earlier parts are dropped. That is correct behaviour but a classic surprise when the part comes from user input.

GetFileName, GetFileNameWithoutExtension, GetExtension, GetDirectoryName and ChangeExtension take a path apart or change one piece. Use them instead of searching for dots and slashes yourself: summary.final.txt has two dots, and only the last one starts the extension.

Relative and absolute#

data.txt means "in the current folder" and the current folder changes with how the program is started. GetFullPath makes the path complete. Programs that should find their own files build the path from a known place, not from the current folder.

Valid names#

Windows does not allow \ / : * ? " < > | in a name. Step 4 replaces each by _. (Path.GetInvalidFileNameChars() has the list of the current system, but it returns a .NET array of characters, so the tutorial writes the list itself.)

Special folders#

Environment.GetFolderPath("MyDocuments") and Path.GetTempPath() give folders that exist on every computer; never write C:\Users\Ali\... in a program.

Environment variables#

An environment variable is a named setting that lives outside the program (set by the user, a script or a server). SetEnvironmentVariable sets one for this process; GetEnvironmentVariable reads it. A variable that does not exist gives null, and .NET null arrives in Ring as an object (not a text): test it with isobject(value), then use your default. Never print a password or a key that came from a variable.

What you learned#

  • Path.Combine and the other Path methods,
  • relative or absolute,
  • valid file names,
  • GetFolderPath, GetTempPath,
  • environment variables and the null object.

Exercises#

  1. Write uniqueName(cFolder, cName) that adds (2), (3) to the name until the file does not exist.
  2. Read a variable MYAPP_FOLDER for the data folder, with the documents folder as the default.
  3. List the extensions found in a folder with how many files each has.
