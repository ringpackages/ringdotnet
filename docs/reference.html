Generated classes#

The wrapper classes are generated; there is one file per class in libraries/dotnetlib/generated/<Namespace>/. The members of a class are the members of the .NET class (see the .NET documentation), named by the rules. To see the Ring name of a method, open its class file or call dnDescribe("Namespace.Type").
