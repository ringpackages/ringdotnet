Quick introduction to Ring

Function index

Every function and class method of the Ring library, generated from the source files — with the comment that documents it.

This page is generated from the comments in libraries/dotnetlib/*.ring. Search it with the box at the top of the page.

Core (functions.ring)#

FunctionDescription
dnRequest(cOperation, aParameters)Send a request to the bridge: dnRequest("call", [oTarget, "Method", arg1, ...]), returns one value. The common answers (a text, a number, a yes/no, one object) are read directly, without making a list of items.
dnFlush()The handles of the objects that Ring freed are released in groups (the next .NET call does it when 32 are waiting). dnFlush() releases them now. Ring frees an object a little after the last variable that held it is gone; callgc() (called in the same function) makes it free the objects at once. So to let go of a big object now (or before you look at the memory of .NET with GC.GetTotalMemory) write: oBig = NULL callgc() dnFlush()
dnVersion()Version of the .NET runtime that is hosted in this process
dnLoad(cPath)Load an assembly (.dll) from a path, returns the assembly name
dnLoadName(dn_cName)Load an assembly by name (for example "System.Xml")
dnType(cTypeName)Get a type (to call its static members), for example dnType("System.Math")
dnNew(cTypeName, aParameters)Create a .NET object: dnNew("System.Text.StringBuilder", ["Hello"]) The arguments can be named: dnNew("StringBuilder",[ :value = "Hello", :capacity = 64 ]) chooses the constructor by the parameter names (the order does not matter). The class is a full .NET type name or the name of a generated Ring class (see dnImport)
dnStatic(cTypeName, cMethod, aParameters)Call a static method: dnStatic("System.Math", "Max", [3, 9])
dnIsNamed(aValue)True for a list of [name, value] pairs, the way Ring passes named arguments: [ :server = "x", :port = 80 ] ([] too)
dnCreateNamed(cTypeName, aNamed)The handle of an object created with named arguments (used by generated code)
dnDescribe(cTypeName)Public API of a type (used by tools/gendotnet.ring)
dnCallback(cCode)Ring code callable from .NET: dnCallback("? aDotNetArgs[1]") or dnCallback("myfunc"), then pass it where a delegate is expected. The code is compiled once into a function (the same code gives the same function).
dnUseDesktop()Use Windows Forms / WPF (adds the Windows Desktop runtime). Call it before any other .NET call.
dnImport(cNamespace)Load the generated Ring classes of a .NET namespace: dnImport("System.IO")
dnImportFrom(cFolder, cNamespace)Load classes generated by tools/wrapassembly.ring for your own assembly: dnImportFrom("myclasses/","MyCompany.Tools")
dnGenericName(cType, aArguments)Name of a closed generic type: dnGenericName("System.Collections.Generic.List",["System.Int32"])
dnNewGeneric(cType, aArguments, aParameters)Create an object of a generic type without a generated class (a DotNetObject: use callMethod/getProp)
dnAssert(dn_cName, xActual, xExpected)Simple test helpers: dnAssert("name",actual,expected) ... dnTestSummary()
dnTestSummary()
dnRegisterClass(cType, cClass, nInit)Register a generated class: objects of this .NET type are returned as instances of the Ring class
dnBuildIndexMap()The index of the generated classes as a hash table (type --> namespace); built once, when it is first needed
dnWrapInto(cInfo)The same, but the object is left in the global oDotNetNew (returning it would copy it once more: a class can have 100 attributes)
dnFindFactory(dn_cChain)The factory function for a chain "type|base type|..." (the most specific type first: a type that is not imported yet is imported on demand before a less specific one is used), or "-" when no class is known
dnNull()The .NET null: oPictureBox.Image = dnNull()
dnUseWeb()Use ASP.NET Core (adds the ASP.NET runtime and loads the web server of RingDotNet). Call it before any other .NET call.
dnUseAll()Windows Forms / WPF and ASP.NET Core together (used by the class generator)
dnUseData()Use Entity Framework Core with SQLite (loads the data assembly of RingDotNet and its packages)

Generated classes#

The wrapper classes are generated; there is one file per class in libraries/dotnetlib/generated/<Namespace>/. The members of a class are the members of the .NET class (see the .NET documentation), named by the rules. To see the Ring name of a method, open its class file or call dnDescribe("Namespace.Type").
