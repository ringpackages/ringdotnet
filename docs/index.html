A first taste#

Ring
load "dotnetlib.ring"
using {
	"System"
	"System.Text"
}

oSB = new StringBuilder("Hello")
oSB.Append(", ").Append("Ring!")
? oSB.ToString()                   # Hello, Ring!
? oSB.Length                       # 12

? new Math().Max(3,9)              # 9
? new Math().Sqrt(144)             # 12

The classes are real Ring classes with the same method names as the .NET ones — like RingQt for Qt — so code completion, inheritance and ordinary Ring syntax just work. There is no eval and no string-based dispatch in your code.

🪟

🗄️

📖
Class referenceEvery wrapped class: constructors, properties, methods with their Ring calls, events — 4,587 types.
📦
Your own assembliesWrap any DLL or NuGet package with one command and use it like the built-in classes.
🎮
43 applicationsCalculator, Notepad, Paint, Tetris, Sudoku, Minesweeper and more — each tests itself.
