# WPF samples

Short samples: windows, panels, controls, XAML, data binding, shapes and rendering, menus, timers. `ring 06_xaml_window.ring` runs one; with `--selftest` it checks itself and closes. Applications: `samples/UsingDotNet/applications/WpfCalculator` (XAML UI) and `samples/UsingDotNet/applications/WpfColorMixer`.
